# GameLibrary 操作录屏脚本

当前 README 使用公开稳定版 v1.5.5 的真实截图，尚无完整录屏。以下是后续实录要求，不是视频占位链接。

## 素材与环境

- 使用独立数据目录与合成示例库，不使用个人游戏、账号、路径或第三方封面。沿用应用默认封面。
- 录制实际桌面应用，标记准确版本、界面语言与构建类型。源码构建不可冒充公开稳定版。
- 示例库使用可安全启动的测试程序，录制前确认扫描、审核、启动流程真实可用。
- 画面 1920×1080，30 fps，文字和鼠标清楚可见。显示比例保持稳定，隐藏通知与个人桌面内容。

## 约 60 秒的操作顺序

| 时间 | 实际操作 | 字幕要点 |
|---|---|---|
| 0–5 秒 | 展示已有示例游戏库 | GameLibrary；版本与语言。 |
| 5–18 秒 | 添加示例文件夹，启动扫描 | 选择游戏所在的文件夹。 |
| 18–32 秒 | 打开候选列表，检查名称与启动文件，确认一项 | 扫描结果需要审核。 |
| 32–45 秒 | 找到新游戏，收藏并分配标签，搜索筛选 | 用收藏和标签整理。 |
| 45–55 秒 | 启动示例程序，关闭后返回游戏库 | 从原始入口启动。 |
| 55–60 秒 | 停留在整理好的游戏库 | 下载入口放在 README，视频不写易失效的版本链接。 |

加载等待可剪短，但不拼接虚构的成功状态。不录制删除、提权或其他与主流程无关的操作。

## 交付

- 完整视频：MP4、H.264、约 60 秒，去除无关声音；四语言字幕用独立字幕文件。
- 封面：从真实录屏取帧，附清楚的播放说明。
- 短演示：可从实录剪出 8–12 秒、宽 960px 的 GIF，控制在约 8 MiB 内，不无限闪烁。
- GitHub README 用封面链接到实际已上传视频；短 GIF 可内嵌。检查实际地址可访问后才添加入口。
