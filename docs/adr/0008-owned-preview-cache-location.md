# ADR-0008 可选择的封面预览缓存位置

- 状态：已接受
- 日期：2026-09-17
- 契约：`catalogVersion=1.1`，`apiVersion=1`；`settings.update` 增加可选 `cacheParentDirectory`（绝对本地目录字符串或 null），`settings.get`/更新响应增加同名字段。旧客户端不传该字段时行为不变。

## 决策

1. 用户在 Desktop 选择“缓存存放位置”的父目录，Host 持久化该路径；CLI/MCP 使用同一个 `settings.update` 字段。null 恢复默认的当前库 `data/cache`。
2. 自定义位置只使用 `<所选目录>/GameLibraryCache/<当前数据目录摘要>/`。Host 写入所有权标记，预览写在其 `previews/` 下；存在但没有正确标记的目录拒绝使用，绝不接管或清理其中的文件。不得递归清空所选父目录。
3. `assets/` 中的用户原图是唯一持久原件；`assets.get` 可生成有尺寸上限的 PNG 封面预览，缓存失败时回退读取原图，不影响游戏卡片。缓存文件名由资产 ID 与原件元数据散列派生，不使用用户路径片段。
4. 切换位置只改变未来读写目标，不搬迁、不删除旧缓存。`diagnostics.cache_rebuild` 只清理当前库拥有的缓存子树；默认位置保留现有内部缓存清理语义。备份不包含可再生缓存。
5. 选中位置必须是已存在的本地绝对目录，路径及祖先不得是重解析点，也不得位于已注册游戏文件夹内；Host 在更新设置时验证，使用与清理前再次复核。用户从 GUI 选择路径，不要求终端参数。

## 理由与被排除方案

- 不把所选目录本身当缓存根：其中可能有用户文件，直接“重建”会误删。
- 不搬迁旧缓存：预览可再生，迁移增加失败与回滚复杂度，却不改善用户数据完整性。
- 不移动 `library.db` 或 `assets/`：那是独立的数据目录迁移问题，需要停机、校验与回退。

## 验证

设置跨 Host/CLI/MCP 持久化；Desktop 文件夹选择和保存 UIA；预览缓存命中、重建再生、自定义父目录中非缓存文件保留、错误标记与链接拒绝、切换和 reset 回退。所有测试仅用 `artifacts/test-runs/<guid>/data`。
