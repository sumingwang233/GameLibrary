# ADR-0001 身份与路径：四种键分离

- 状态：已接受
- 日期：2026-09-13（T20）
- 负责人：单 agent 开发；共享契约变更先登记版本再修改

## 决策

一个 Game 代表一个本地安装实例，身份体系使用四种互相独立的键：

1. **PhysicalPath**：原始真实路径，原样保留中文/日文/方括号/百分号/空格，不做字符替换。
2. **ComparisonKey**：仅用于路径相等判断、去重与数据库唯一约束；按 Windows 语义（OrdinalIgnoreCase、分隔符与 `.`/`..` 折叠、分段边界比较）在应用层生成，不依赖 SQLite NOCASE。
3. **GameId**：独立随机 GUID，用户资料与启动配置的永久关联键；**绝不**由路径+引擎+哈希派生。
4. **MatchFingerprint**：重新关联/相似副本**建议**的证据组合（策略版本+关键文件摘要+时间），可能碰撞、可能失效，不是身份。

F 盘为 exFAT：不得依赖 NTFS FileId/USN/硬链接；卷序列号仅作挂载提示。

## 理由

移动、重命名、升级、复制都会改变路径与文件内容；用内容派生身份会在用户资料层面造成假死。exFAT 无稳定文件 ID，Windows 大小写规则不能用数据库排序规则完整表达。

## 被排除方案

- 路径+哈希做主键：改名即丢资料；同路径换内容即换身份。
- 依赖 NTFS USN/FileId：F 盘 exFAT 直接不可用。
- SQLite NOCASE 唯一索引：Unicode 路径语义不完整。

## 不可变约束

- GameId 一经分配永不重算；relink 只改数据库绑定，绝不移动磁盘文件。
- 非法路径输入（双引号、NUL、ADS 语法、不支持的尾空格/尾点别名）返回 InvalidPath/UnsupportedPath，不构造“近似合法”路径。
- 路径前缀比较必须按分段边界（`F:\Games2` 不属于 `F:\Games`）。
- UNC/设备命名空间路径返回 UnsupportedPath；根内重解析点默认不跟随。

## 迁移影响

ComparisonKey 生成规则版本化（策略版本号），规则演进需全量重建键并核对原值碰撞。

## 验证用例

ID-01（同名不同路径不合并）、ID-02（离线移动保 GameId）、ID-03（副本不自动合并）、T01 单元测试（大小写/分隔符/非法输入/分段边界）。
