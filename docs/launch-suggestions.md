# 建议启动方式（v1.6.1）

2026-10-01，基于 `7f6b57d` 审计后实施。版本按维护者本次明确要求使用 v1.6.1；本次新增功能是版本策略的显式例外。公开稳定版仍以已完成验收的下载为准。

## 现状与证据

原有 `EngineDetectorSet` 已输出入口分数，`EntryScoring.MeetsPrescore` 已规定 ≥80、领先 ≥25，但启动配置和前端未消费这个推荐规则。此前前端在没有默认配置时直接选择第一条 Profile，无法表达歧义。

现有用户库只读调研：295 个活跃游戏有默认配置，308 条活跃启动配置；307 条 argv 为空，308 条 cwd 均为 EXE 父目录，入口全部是 EXE，默认入口全部位于游戏目录第一层。因此首版采用顶层 EXE、空参数、EXE 父目录，不自动猜测快捷方式参数或递归搜入口。

生产检测器对 295 个现有默认入口的只读回测：231 个直接推荐与手动配置一致，61 个保留歧义，3 个无可推荐入口。数据只作本地汇总，没有保存用户库、标题或个人路径，也没有启动真实游戏。该结果表示样本中的一致性，不代表未见游戏的准确率。发现的 `app.exe`/`bin.exe` 与外层启动器并存案例已降为歧义。

## 实现和边界

- `LaunchSuggestionDetector` 复用引擎证据与原评分门槛，优先带明确中文标记及原版配对的入口。排除安装、卸载、崩溃和设置程序，保留真实样本中的 stop/protect 等名称。第一层最多 256 个文件与目录；离线、权限不足、枚举不完整和 reparse point 均不作直接推荐。
- `LaunchSuggestionService` 使用单后台执行器，每 5 秒检查新游戏和修订变化，按游戏持短库租约；`profiles.discover` 可显式重新识别。既有配置不重复添加，手动配置优先，既有默认不变。库切换按连接代数丢弃旧任务状态。
- 自动入口记录 `suggested/verifying/verified/discarded/inconclusive`；人工配置保留 `manual`。启动观察每 500ms 采样，连续 30 秒存活才验证，120 秒内不满足则待确认。Win32 Toolhelp 按父子关系、启动时间、游戏目录和持有的进程句柄跟踪多层游戏子进程，维持同一次 attempt、同游戏互斥和整段时长。
- 只把无效 EXE（Win32 193/216）及观察到的典型早期崩溃 NTSTATUS 当作明确失败。退出码非零、正常短退、Ctrl+C、UAC 取消、权限不足、缺失运行库、翻译路由不可用和观察不确定都不会自动废弃。翻译配方失败不能被误判成原始游戏入口失败。已验证的默认配置不会因后续试运行重新废弃。
- 自动晋升通过持久层单条条件 UPDATE 原子检查修订、自动来源、状态、活跃库籍及无其他默认；内存 Profile 变更串行，用户手动选择优先。没有人工默认时才自动晋升。
- Schema 25 在 `launch_profiles` 添加来源、验证状态及评分证据，历史配置以 manual 原样保留。删除入口保留不可见 `deleted` 行作为抑制记录，兼容 get/list 的已删除语义；扫描及同路径换文件不能重新添加。废弃项可手动恢复，删除项可通过明确恢复 API 或重新手动配置恢复。没有删除原游戏文件。
- 保留 `launch.plan → launch.execute` 与 Required 翻译验证；新增 `profiles.discover/restore` 同步到 CLI/MCP/权限/幂等目录。Profile DTO 增加可选元数据，list 增加 `recommendedProfileId`。前端优先默认、其次后端唯一建议；歧义打开详情的启动标签，不取第一条猜测。旧 Host 保持原手动流程。
- `profile.updated` 驱动前端刷新，详情仅刷新启动配置，不覆盖用户尚未保存的标题输入。图标、游玩时长和主题按钮包含本会话已完成的三个修复。

## 验收与回滚

检测规则测试覆盖中文配对、同分歧义、单入口、Unity、辅助程序、内层二进制及枚举上限；生命周期测试使用隔离 TestProcessStub，覆盖真实 30 秒、短退、崩溃、启动器交接、互斥、幂等、编辑/默认/删除/移除/切库竞争、超时和 v24→25 数据保留与迁移前快照。

自动构建、全量测试、最终资产和 WebView 检查以本次生成的 `artifacts/dist/release-validation.json` 为准，未执行项不得写成通过。Win10/11 干净环境、全部 DPI、真实示例游戏人工验收仍需登记，发布为预发布。

回滚程序前先备份。Schema 25 不自动降级；旧程序拒绝较新 schema，需要使用迁移前快照或相容备份恢复。代码可 revert 本次功能提交，三项早先 UI 修复分别在 `97d6980`、`ae3d9b6`、`7f6b57d`。
