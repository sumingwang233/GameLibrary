## 根因与结果

1. 盘根的 Godot 内嵌 PCK 识别正确，但候选编排把盘根当作 GameRoot，随后 `ShouldDescend` 剪掉整个盘。盘根现按独立文件产生候选，仍遍历子安装目录；普通安装根与 Flash 审核边界保留。
2. ExactPath 与 Subtree 原先都在 Walker 中剪枝。移植旧 `45bfbff` 的共享规则/Walker 修复及专项回归，未带入旧版本字段。根目录、嵌套目录和续扫均保留精确忽略目录的后代。
3. 待确认徽标叠加候选数与包含同一候选的通知数。改为仅显示候选 total，分页不改变总数。
4. LNK 与目录使用不同 RootPath，原有仅按 RootPath 的检查不能防重复。自动扫描不再发现 LNK；手动导入、扫描落库和候选接受复用保守入口索引。唯一 Unreal 打包结构才能建立 wrapper/Shipping 对应关系；同名、祖先路径或歧义不会合并记录。
5. 旧错误盘根仅在本轮实际读取、仍属注册 library 扫描范围、pendingReview 且无 gameId 绑定时转为 deferred；保留 ID/payload，事务后刷新通知。accepted、绑定游戏、用户忽略/暂缓和离线未观察分支保留。
