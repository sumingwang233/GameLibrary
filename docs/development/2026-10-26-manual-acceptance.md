# 本轮优化的人工验收清单

2026-10-26。自动测试覆盖到了逻辑层，但下面这些只能在真实窗口、真实 Host 进程和真机上确认。每一条都写清操作、期望和失败时要记的东西；发现问题时把现象、操作顺序和界面提示记下来，能截图就截图。

前置：用本轮代码构建的程序（或 `npm run tauri build` 产物），准备一个至少有 80 个游戏、其中若干带封面的游戏库；另外准备两个 Unity 游戏的翻译配置场景。

## 一、Host 连接与作业

| 场景 | 操作 | 期望 |
| --- | --- | --- |
| Host 被杀后恢复 | 打开程序，任务管理器结束 `GameLibrary.Host` 进程，回到界面点刷新、再点一个游戏的“启动” | 不需要重启界面：列表刷新自动把 Host 拉起来并重连；启动按钮正常工作。若失败，记录提示文字和是否要求重启程序 |
| NotFound 提示 | 制造一次“作业在 Host 侧已不存在”（例如刷新列表期间结束 Host，让正在轮询的扫描/翻译作业丢失） | 扫描/翻译进度条停下并给出中文错误，不再每 0.5–0.7 秒反复请求；界面不卡死。可配合开发者工具的网络/IPC 日志确认请求已停止 |
| 分页期间增删改 | 列表滚到第二、三页，期间导入一个新游戏（或给游戏改封面、改标题），继续滚动 | 不重复、不漏条目；新导入或改动的游戏在刷新后出现在正确位置，滚动不会卡在“加载中” |
| 详情新鲜度 | 打开某游戏详情，保持详情不关，回列表把它的标题或封面改掉 | 详情里显示新标题/新封面，不是打开时的旧快照；关掉详情再开也一致 |

## 二、审核与翻译

| 场景 | 操作 | 期望 |
| --- | --- | --- |
| 部分审核失败 | 勾选多个候选，其中包含一个提交前已失效/已处理的候选，执行“接受” | 成功项从勾选中移除，失败项保持勾选；顶部错误提示写明失败数量，成功项确实已生效。不能出现“全清空但有一项没生效” |
| 两个游戏同时配置翻译 | 同时打开两个 Unity 游戏的翻译设置，先后各提交一次配置 | 两个游戏各自显示提交中/成功/失败，状态不互相覆盖；重复点同一游戏不会重复提交 |
| 翻译作业丢失 | 翻译进行中结束 Host 进程 | 翻译轮询停止并提示错误，列表刷新一次后不再空转 |

## 三、批量操作

| 场景 | 操作 | 期望 |
| --- | --- | --- |
| 批量收藏/取消 | 列表按住 Shift 或勾选框选中 3 个游戏，点批量收藏 | 一次操作完成三个；结果文案显示“已完成 3 个”；期间不逐个闪烁 |
| 批量加标签 | 选中 3 个游戏，选一个标签批量添加 | 三个都挂上标签；重复添加同一标签不会报错 |
| 批量移除 | 选中 3 个游戏执行移除 | 三条记录从库中消失，磁盘文件仍在；有冲突（比如记录刚被别的操作改过）时给出失败计数，而不是整批失败 |
| 失败提示 | 对刚被修改过的游戏执行批量收藏 | 提示里出现失败数量与原因，成功的项仍然生效 |

## 四、键盘、屏幕阅读器与动效

| 场景 | 操作 | 期望 |
| --- | --- | --- |
| 详情对话框命名 | 键盘打开任意游戏详情 | 屏幕阅读器报出对话框名称等于游戏标题，描述可读；Tab 不会跑到背景内容 |
| 卡片键盘操作 | Tab 遍历列表 | 每张卡可聚焦，Enter/Space 打开详情；收藏复选框与启动按钮能各自独立聚焦、独立触发，不误开详情；选中状态有可感知的视觉反馈 |
| 扫描进度播报 | 开始扫描，开着屏幕阅读器 | 进度区域只在阶段变化时播报，不会每秒念一次计时数字；取消按钮可聚焦、有名称 |
| 徽章对比度 | 在暗色与亮色主题下看列表徽章文字 | 文字清晰可读，不需要凑近看；与背景对比明显（本轮把 11px 文本提到 4.5:1 以上） |
| 减少动态效果 | Windows 设置里打开“减少动画”，再开关详情、悬停卡片、加载骨架 | 详情无位移/淡入淡出、骨架不脉冲、卡片不抬升；布局不跳动 |

## 五、安全与性能

| 场景 | 操作 | 期望 |
| --- | --- | --- |
| 更新检查（若启用 CSP 草案） | 按优化记录里的 CSP 草案写入 `tauri.conf.json`，重新构建后启动 | 窗口正常渲染、封面显示、更新检查能返回结果、详情滚动与对话框动画正常；白屏或样式丢失说明允许清单还缺项，按控制台报错补 |
| 封面缓存内存 | 连续滚动列表把几十张封面都看过一遍，再重复两轮；同时任务管理器看进程内存 | 内存增长有上限、不持续攀升；切到别的页面再回来封面不重新闪白 |
| 大库分页 | 用接近 5000 个游戏的库，连续翻 20 页 | 每页切换流畅（本机基线 p95 远低于 150 ms），没有明显卡顿或长时间白屏 |

## 发现问题时记录什么

- 操作顺序（点了什么、什么时候结束的 Host）、界面提示原文、是否能复现。
- Host 与前端日志里的错误行（时间点对齐操作时间）。
- 如果是性能问题，记下游戏数量、页码和大概耗时，别只写“有点卡”。
