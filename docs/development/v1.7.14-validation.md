## 关键异常场景

- 作业终态记录写入失败：等待能够结束，活动数量归零，待补写数量可见；存储恢复后补写原始结果，执行器仅运行一次。实际 restore history 文件锁失败及解除后补写，重新打开历史仍读取原成功结果。
- 管道：发送锁排队时取消不破坏连接；请求已收到后取消、半帧、错误 requestId 关闭当前连接，明确重连后 B 读取 B 的响应。旧客户端握手读取到 Host 的实际版本。
- 审计：400 条并发记录与轮换后 JSONL 完整且 ID 唯一，最近 7 条顺序正确；真实文件锁导致失败计数增加。
- 详情：A → B → A 的旧成功/错误、旧操作的 error/finally 与 B 的 busy、较旧 revision、简介脏草稿与冲突、保存期间再次输入均有回归。
- 缓存组合：B 卡片正在读取封面时，A 的实际 API 写入回执和资产事件不会拒绝 B；库身份/纪元切换拒绝旧库封面。
- 候选：1,001 项分批加载，插入/删除后重建已加载窗口，重复页停止，旧 append 晚于新刷新返回也不覆盖新列表；批量选择只覆盖当前已加载且仍存在的 ID。

从仓库根目录运行后端与安装专项：

