# GameLibrary v1.7.18

## 简体中文

本次交付本地待验收安装包和源码，尚未创建 GitHub Release。包含 v1.7.17 的 MTool 自动配方功能与本轮 Mono 翻译、游戏状态和引擎识别更新。

### 主要变化与修复

- 修复 BepInEx Mono 已加载新版插件，但旧 Rei 核心抢先绑定、找不到 DeepSeekTranslate 端点的问题。只有匹配固定原版摘要的冲突文件才会备份停用，未知 MOD 保留；失败回滚，恢复后可重试。
- 详情页收藏按钮改为独立的已游玩状态；正常游玩退出后自动标记，可手动切换，原收藏数据保留。
- 游戏可评 1–5 星或清除评分；退出后回到详情，评分区短暂高亮，并遵循减少动态效果设置。
- 手动添加游戏时按实际文件识别引擎并自动分配引擎标签，Unity 游戏可显示对应翻译入口。后台与重扫只补齐未知引擎，保留已有识别结果和用户标签抑制。
- 移除侧栏收藏夹分组，让 Tags 使用空出的空间；上方收藏筛选保留。
- 共享扫描、手动建卡和 MTool 的识别证据，扩充 RGSS XP/VX/VX Ace、WOLF、SRPG Studio、Pixel Game Maker MV、Bakin、Godot、Unreal、Tyrano；加强 Unity 多数据目录配对和 Kirikiri 嵌入发行版识别。
- 添加未翻译标签时尝试生成受支持的 MTool 配方，启动时兜底检查或修复。专属缓存、入口或工具路径缺失时显示原因，保留原配方备份。

### 升级与数据保留

请从托盘退出 GameLibrary 后安装新版。升级 v1.7.13 及更早版本或未知版本前，请关闭所有 GameLibrary 实例，以兼容旧卸载器。游戏库和原游戏保留；schema 29 自动备份后增加已游玩和评分字段，旧收藏不转换为已游玩。回退到旧程序前，需使用迁移前的库快照。

受端点冲突影响的游戏，更新后点击“配置或重试翻译插件”应用修复。识别引擎不等于该引擎已支持自动翻译注入，未知或不完整证据继续保留人工处理。

## English

This delivery contains local acceptance-candidate packages and source changes; no GitHub Release has been created. It includes MTool recipe preparation from v1.7.17 and the Mono translation, game experience and detection updates in v1.7.18.

### Highlights and fixes

- Fix legacy Rei assemblies shadowing the BepInEx Mono core and hiding the DeepSeekTranslate endpoint. Only files matching pinned originals are backed up and disabled; unknown mods are preserved, failed changes roll back, and configuration can be retried after restore.
- Replace the detail favorite button with an independent played state. A normal successful exit marks the game played; manual toggling and existing favorites remain available.
- Add game ratings up to five stars, clearing and a brief rating highlight when returning from a session, respecting reduced motion.
- Detect real engine evidence when manually adding games, assign engine tags and show Unity translation controls. Background reconciliation and scans fill unknown engines without changing recognized values or suppressed tags.
- Remove the saved-folder section from the sidebar to give Tags more space, keeping the favorites filter.
- Share detection across scans, manual import and MTool preparation; add RGSS variants, WOLF, SRPG Studio, Pixel Game Maker MV, Bakin, Godot, Unreal and Tyrano evidence, and improve Unity data-directory pairing and embedded Kirikiri detection.
- Prepare supported MTool launch recipes when the untranslated tag is assigned and check or repair them before launch. Missing dedicated caches, entries or tools produce an explicit reason and preserve backups.

### Upgrade and data preservation

Exit GameLibrary from the tray before installing. Close all GameLibrary instances before upgrading v1.7.13 or earlier, or an unidentified version, to protect against older uninstallers. Library data and original games are preserved. Schema 29 adds played and rating fields after a backup; favorites are not converted to played. Restore a pre-migration library snapshot before downgrading to an older application.

For affected games, select “Configure or retry translation plugin” after updating. Engine identification does not imply support for automatic translation injection.

### Validation and limitations

Source `68edb90` passed 213 distinct focused checks and necessary compilation. Isolated experiments using the reported games’ Mono runtimes verified core shadowing, repair and restoration. Full release gates, online in-game translation, final WebView, clean Windows, installation/upgrade/uninstallation, language/DPI and keyboard acceptance remain unrun. This is not a stable release.
