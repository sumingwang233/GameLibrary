# GameLibrary v1.7.4

## 简体中文

修复 Unity 翻译自动化、后台重复工作、退出后的 Host 残留和标签底色。

### 变更

- 添加「未翻译」用户标签后，Unity 游戏进入既有插件配置队列；小写 `unity` 的真实库记录与详情重试入口正确识别。
- 已安装且启用、目标为简体中文、能够确认翻译端点的 XUnity 插件自动解除绑定的未翻译标签。仅有 DLL、加载器关闭、配置不完整或用户已明确否定的记录保留标签；新安装仍通过弹窗让用户启动和确认效果。
- 建议入口发现改为等待库事件，保留五分钟兜底；库维护时短暂重试。缓存命中的游戏不再逐项重读，共享目录入口用索引查询。候选核对仅加载必要路径字段，跳过已归并的历史资源，保留原记录。
- 桌面退出时 bridge 不再等待长轮询锁；关闭输入或监视到桌面结束后通知对应 Host 优雅停机。扫描及翻译任务按原取消/回滚边界结束，游戏进程和其他数据目录不被关闭。
- 标签自定义颜色只应用于文字和圆点，移除自动黑白底色。

### 升级与数据

退出旧版 GameLibrary 后安装新版。保留现有游戏库数据目录；本版继续使用 schema27。现有翻译服务设置和本机 DPAPI 密钥引用继续使用，私人 API Key 不包含在源码或发布包中。后台检查只做离线验证，不发送翻译请求；已有插件的自动标签清理不等于联网翻译结果验收。

## English

Fixes Unity translation automation, redundant background work, lingering Host processes after desktop exit, and tag backgrounds.

### Changes

- Correctly handle canonical lowercase `unity` records in tag-triggered setup and retry controls.
- Remove the bound untranslated tag when an existing enabled Chinese XUnity translator and endpoint pass offline checks. Incomplete, disabled or explicitly declined configurations keep their tag. Newly installed translators retain the launch and user-confirmation prompts.
- Wait for library events between discovery passes, with a five-minute fallback and short retries during maintenance. Reuse cached game revisions and indexed shared entries. Read only necessary candidate path fields, preserving retired resource history.
- Monitor the desktop parent and request graceful shutdown of the corresponding Host without waiting for busy bridge locks. Cancel scans and translation jobs through their existing rollback paths; leave games and other data scopes running.
- Apply custom tag colors only to text and dots.

### Upgrade and downloads

Exit the old app before upgrading. Keep the library data directory; schema27 and existing local provider credentials are preserved. Offline recognition does not test an online translation response or invoke a paid API.

Download Setup, Portable or Tools and verify them with `GameLibrary-v1.7.4-SHA256SUMS.txt`.

### Validation and limitations

See the [validation record](v1.7.4-validation.md) for final assets, signing status and release readiness. Checks not performed must not be reported as passed.
