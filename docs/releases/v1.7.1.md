# GameLibrary v1.7.1 — 待验收预发布 / Acceptance pre-release

## 简体中文

修复翻译引擎把标题中的连字符扩成长破折号，导致游戏卡片名称冗长的问题。

### 主要变化与修复

- 原文含 `-` 时，自动将译文内部连续长破折号收为 `：`，移除首尾包围符和符号两侧空白。例：`カノジョの性癖 -盗聴×妄想-` 的译文从 `女友的癖好——偷听×妄想——` 收为 `女友的癖好：偷听×妄想`。
- Google/Bing、单个和批量翻译共用后端规则。原文没有 `-`、译文只有单个 `—`、手工编辑的译名保持原样。
- 已有译名不会自动改写。在详情点击「重新翻译名称」即可应用修复，重新翻译仍使用原文。

### 升级与数据保留

先退出 GameLibrary，再安装新版或替换便携版程序文件。保留游戏库数据目录和原游戏。与 v1.7.0 共用 schema26，不新增迁移；v1.7.0 可读取本版本的译名。更旧版本回退前需备份并恢复相容数据库，不能直接写入 schema26。

## English

Fixes verbose translated game titles when translation engines expand hyphens into repeated em dashes.

### Highlights and fixes

- When the original contains `-`, repeated em dashes inside a translation become `：`; surrounding dashes and adjacent whitespace are removed. A title such as `女友的癖好——偷听×妄想——` becomes `女友的癖好：偷听×妄想`.
- The shared backend rule covers Google/Bing and individual/batch translation. Originals without `-`, single em dashes and manually edited translations are preserved.
- Existing translations are retained. Use the retranslation action in details to apply the fix; it always translates the original title.

### Upgrade and data preservation

Quit GameLibrary before installing or replacing portable files. Keep the library data directory and original games. Uses the same schema26 as v1.7.0 without migration; v1.7.0 can read these translations. Before rolling back to older versions, back up and restore a compatible database: they cannot write schema26.
