# v1.7.7 — Unity BepInEx 简体中文配置修复

**待验收预发布。** 修复 IL2CPP 翻译插件安装成功后仍把日语译成英语的问题，Mono BepInEx 使用相同修复。

## 变化

- 按真实加载器选择配置文件：BepInEx 使用 BepInEx/config/AutoTranslatorConfig.ini，Rei 使用 AutoTranslator/Config.ini；目标简体中文 zh，源语言自动识别。
- 安装后与启动前检查实际插件读取的配置，错误位置的中文配置不再被误判为已配置。
- 启动时修复程序曾托管安装的旧错误配置，已移除“未翻译”标签也可修复。游戏运行中暂不处理；关闭游戏后重启 GameLibrary，或在详情页添加未翻译标签并重试配置。
- 保留自定义模组值、英文缓存和原始备份，沿用文件哈希校验及恢复。用户拒绝或未托管的安装不自动改动。
