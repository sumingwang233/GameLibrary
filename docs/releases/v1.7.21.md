# GameLibrary v1.7.21

## 简体中文

本次交付本地待验收安装包：把“已游玩”改为只在游戏详情页手动标记，正常退出游戏不再自动把游戏划入已游玩库。

### 主要变化

- 游戏详情页的“标记为已游玩/已游玩”按钮是唯一的标记入口。标记后游戏从主库移动到侧栏“已游玩”，取消后回到主库。
- 正常退出游戏只记录退出事件和游玩时长，不再自动改变已游玩状态；成功、失败和崩溃退出都一样。

### 修复

- 之前版本在游戏以退出码 0 正常结束后自动标记已游玩，用户无法区分“玩过”和“自己判定通关/全收集”。现在已游玩完全由用户决定。

### 升级与数据保留

先退出 GameLibrary（托盘退出），再安装新版或替换便携版文件。本版没有新增数据库迁移。升级前已经标记的已游玩状态不会被清除：schema 29 的历史成功退出回填和之后产生的自动标记无法与手动标记安全区分，如不需要可在详情页逐项取消。评分、收藏、标签、入库时间和游玩统计不受影响。回退程序前确认库兼容性，旧包与旧说明保留。

## English

This delivery provides local acceptance-candidate packages: Played is now a manual-only mark set from the game detail page, and a normal exit no longer files a game under Played automatically.

### Highlights

- The Mark as played / Played button on the game detail page is the only way to set the state. A marked game moves from the main library to the sidebar Played entry; clearing the mark returns it to the main library.
- A normal exit only records the exit event and playtime. Successful, failed and crashed exits all leave the played state unchanged.

### Fixes

- Previous versions automatically marked a game as played after it exited with code 0, so users could not distinguish "launched once" from a self-judged completion. Played is now entirely user-controlled.

### Upgrade and data preservation

Exit GameLibrary from the tray before installing or replacing the portable files. This release adds no database migration. Played marks that already exist are not cleared: the schema 29 historical backfill and later automatic marks cannot be safely distinguished from manual marks, so unmark any unwanted entries in the detail page. Ratings, favorites, tags, addition time and playtime statistics are unaffected. Check database compatibility before downgrading; older packages and notes remain available.
