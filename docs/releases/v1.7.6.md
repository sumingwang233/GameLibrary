# GameLibrary v1.7.6

## 简体中文

**待验收预发布。** 本次修复模块化 Unity Mono 游戏自动安装翻译插件失败，并补充 Windows x86/x64 IL2CPP 游戏自动配置。针对性回归与生产编译分别记录，真实游戏内翻译效果仍需用户确认。

### 主要变化

- 修复离线补丁缺失 `UnityEngine.SharedInternalsModule` 等 Managed 依赖导致的写入失败；失败时保留标签与原文件，并显示具体依赖错误。
- 自动识别 IL2CPP 和 EXE 位数，配置匹配的 BepInEx 6、XUnity.AutoTranslator IL2CPP 插件以及现有本机翻译服务设置。完整的既有 IL2CPP BepInEx 可只补装翻译插件；混用 Mono 加载器、未知模组冲突和残缺运行环境仍需人工处理。
- 游戏详情的配置重试与未翻译标签自动配置共用流程；配置完成后可经用户确认启动。首次 IL2CPP 启动可能联网准备组件，实际翻译成功前不会因重复检查自动移除未翻译标签。
- 没有就绪的 Unity 插件时，启动提示引导重新配置，不再只报告未发现 MTool 配方。安装采用固定版本和 SHA-256，包含路径、位数、文件冲突、并发变更及备份回滚保护。

### 升级与下载

保留游戏库、原游戏、标签和已保存的本机凭据；数据库仍为 schema27。首次配置按既有本机设置使用 DeepSeek 或自定义 OpenAI 兼容服务。API Key 不写入仓库、Release 或公开日志。

验证与限制见[本次记录](https://github.com/sumingwang233/GameLibrary/blob/main/docs/releases/v1.7.6-validation.md)。未完成的真实游戏、干净 Windows 与全量验收不视为通过。本次未签名，请核对校验清单；上一版 v1.7.5 的验收豁免不延伸到本版本。

本次后端针对性回归 67 项分组通过，前端专项 18 项通过，四语言检查通过；生产程序和安装器编译完成。真实游戏副本仅用于隔离离线诊断，未启动原游戏或调用翻译 API。

## English

**Prerelease awaiting acceptance.** Fixes automatic translation installation for modular Unity Mono games and adds Windows x86/x64 IL2CPP configuration. Targeted regression results and production compilation are recorded separately; actual in-game translation still requires user confirmation.

### Changes

- Resolve original Managed dependencies such as `UnityEngine.SharedInternalsModule` when writing an offline Mono patch. Preserve files and tags on failure and report the dependency problem.
- Detect IL2CPP and executable architecture, then configure matching pinned BepInEx 6 and XUnity IL2CPP packages using the existing local translation provider. Complete existing IL2CPP BepInEx installations can receive just the translation plugin; conflicting or incomplete loaders require manual review.
- Share tag-triggered configuration and detail-page retry, retain the untranslated tag until first-install confirmation, and explain that the first IL2CPP launch may need internet access and time to prepare components.
- Guide Unity users to configuration retry instead of reporting only a missing MTool recipe. Preserve hash-pinned downloads, path and architecture checks, conflict protection, backups and rollback.

Library data, original game files, tags and local credentials are preserved; database schema remains 27. Private API keys are excluded from source, assets and public logs. Assets are the Setup, Portable-win-x64, Tools-win-x64 and versioned SHA256SUMS files above. Packages are unsigned. See the [validation record](https://github.com/sumingwang233/GameLibrary/blob/main/docs/releases/v1.7.6-validation.md); unexecuted full and manual acceptance is not a pass. The v1.7.5 waiver does not apply to this version.

Targeted backend regressions passed in groups (67 cases), along with 18 frontend cases and four-language checks. Production and installer compilation completed. Real assembly copies were used only for isolated offline diagnosis; the original game and translation APIs were not invoked.
