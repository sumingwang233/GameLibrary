# GameLibrary v1.7.0 — 待验收预发布 / Acceptance pre-release

## 简体中文

新增游戏名称翻译：无需账户或 API 密钥，将单个或多选游戏的名称翻译为简体中文，并保留原文。

### 主要变化

- 详情 → 概览 →「翻译为简体中文」，或勾选游戏后点击「翻译选中名称」。成功的译名立即显示在卡片上。
- 详情中可切换显示原文 / 中文译名，分别编辑和保存；已保存的名称和显示偏好可离线使用。
- 设置 → 游戏库 → 名称翻译，可选择负载均衡、Google 优先或 Bing 优先。支持失败切换、进度、取消与重试；默认跳过已有译名，重新翻译始终使用原文。

### 修复

- 网格和紧凑布局都在游戏标题下方显示游玩时长，替换引擎信息；未游玩时显示 0 分钟。

### 升级与数据保留

先退出 GameLibrary，再安装新版或替换便携版程序文件。保留游戏库数据目录与原游戏文件。数据库 schema 25 自动迁移到 26，并保存迁移前快照；原游戏名称保留，译名与显示偏好单独存储。回退前先备份，旧版本不能直接写入 schema 26，需要恢复相容备份或迁移前快照。

## English

Translate individual or selected game titles into Simplified Chinese with Google/Bing, without an account or API key, while keeping the original titles.

### Highlights

- Use the translation action in Details → Overview, or select games and translate their titles together. Successful translations appear on cards immediately.
- Switch between original and Chinese titles in details, edit them separately, and retain saved titles and display preferences offline.
- Choose balanced, Google-first or Bing-first routing in Settings → Library. Includes fallback, progress, cancellation and retry. Existing translations are skipped by default; retranslations always use the original title.

### Fixes

- Both grid and compact layouts show playtime below the title instead of engine information, including zero minutes for unplayed games.

### Upgrade and data preservation

Quit GameLibrary before installing or replacing portable application files. Keep the library data folder and original games. Schema 25 migrates to 26 with a pre-migration snapshot; original titles remain intact and translations/display preferences are stored separately. Back up before rolling back: older versions cannot write schema 26, so restore a compatible backup or pre-migration snapshot first.

### Validation and limitations

- All 604 .NET and 41 frontend tests passed, together with version, formatting, type, generated operation and localization checks. See the [validation record](https://github.com/sumingwang233/GameLibrary/blob/main/docs/releases/v1.7.0-validation.md) for build and asset evidence.
- A real network smoke test using this Release Host translated neutral text `Summer memories` into Chinese through Bing. Google returned HTTP 429 on this network. Free endpoints may be rate-limited or unavailable; retry later or change provider preference.
- Translation sends only game titles to the provider when requested. Paths and game files are not sent; original titles are preserved.
- Final desktop EXE, clean Windows 10/11, DPI, real games and production installer upgrade/uninstall acceptance remain pending. This is a pre-release; stable downloads remain at v1.5.5.
- No publisher signing identity is configured. Windows may show an unknown publisher prompt; verify downloads against the versioned SHA-256 manifest.
