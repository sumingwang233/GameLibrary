# GameLibrary v1.7.22

## 简体中文

v1.7.22 已于 2026-10-22 正式发布并设为 Latest。Godot 内嵌 PCK 游戏可被识别，并可在详情页标记翻译、生成 MTool GodotHook 启动脚本。维护者明确豁免了本次未完成的验收；未执行项仍保留原记录。

### 主要变化

- 扫描与元数据核对会自动识别内嵌 PCK 的 Godot 导出（文件尾 trailer + 包头校验），写入 `godot` 引擎并分配引擎标签，无需重新扫描。
- 游戏详情页“MTool 翻译”：未标记翻译的游戏按钮显示“标记为需要翻译并生成启动脚本”，点击后写入显式翻译需求并生成 MTool 配方；开始游戏后经 `inject.exe + GodotHook.dll` 注入，MTool 提供翻译文本。

### 修复

- 之前内嵌 PCK 的 Godot 导出（没有 `.pck` 文件、PE 版本串为空）识别为未知引擎，MTool 生成报“无法确认适用的 MTool 加载器”。现在使用定长读取的第三种 Godot 证据，不扫描整个文件、不按工具文件名猜测。
- 之前详情页按钮在游戏未标记翻译时静默返回“游戏当前不需要翻译”，与界面“点击生成即可”不一致；现在按钮先写显式 `Required`，显式 `NotRequired` 不会被覆盖。

### 升级与数据保留

先退出 GameLibrary（托盘退出），再安装新版或替换便携版文件。本版没有新增数据库迁移；引擎识别在 Host 启动与元数据核对时自动补齐。既有游戏 ID、评分、收藏、标签、封面、启动方式与翻译策略不变。回退程序前确认库兼容性，旧包与旧说明保留。

## English

v1.7.22 was formally published and marked Latest on 2026-10-22. It recognizes Godot games with an embedded PCK and can mark translation and generate an MTool GodotHook launch script from game details. The maintainer explicitly waived the incomplete acceptance gates; unrun items retain their original status.

### Highlights

- Scanning and metadata reconciliation detect Godot exports with an embedded PCK (file-tail trailer plus pack header), write the `godot` engine and assign its engine tag without a rescan.
- MTool translation in game details: for a game that is not yet marked for translation, the button reads Mark as translation-required and generate launch script. It writes the explicit requirement and generates the MTool recipe; launching then injects `inject.exe + GodotHook.dll` while MTool provides translated text.

### Fixes

- Godot exports with an embedded PCK (no `.pck` file, empty PE version strings) were previously detected as an unknown engine, so MTool generation reported that no applicable loader could be confirmed. A third Godot evidence now reads fixed-size byte ranges instead of scanning the executable or guessing from tool file names.
- The detail-page button previously returned a silent "game does not need translation" when the game was not marked. It now writes an explicit `Required` first; an explicit `NotRequired` is never overwritten.

### Upgrade and data preservation

Exit GameLibrary from the tray before installing or replacing the portable files. This release adds no database migration; engine recognition is backfilled on Host start and metadata reconciliation. Game IDs, ratings, favorites, tags, covers, launch profiles and translation policies are unchanged. Check database compatibility before downgrading; older packages and notes remain available.

Packages are unsigned and were not installed automatically. See the [build record](v1.7.22-validation.md) for production compilation and package integrity results.
