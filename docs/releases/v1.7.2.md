# GameLibrary v1.7.2 — 待验收预发布 / Acceptance pre-release

## 简体中文

增加封面粘贴、Flash 目录审核和 Unity 游戏内翻译插件自动配置，并修复标签颜色显示。

### 主要变化与修复

- 在详情页点击「开始游戏」上方封面，Ctrl+V 粘贴图片。目录游戏保存 `cover.png`，单文件游戏使用各自的 `<文件名>.cover.png`；WebP 保留 `.webp` 格式。替换前保留历史封面，可从历史恢复；自动扫描不会覆盖手动封面。
- Flash 按目录审核项目、独立游戏合集或资源目录。有效 SWF 只证明格式，不能证明它是完整游戏。明确入口并预览调整清单后才提交；只从库中移除误识别记录，保留元数据和原文件。混合目录分别保留直属 SWF 和子项目，保存的判断可供下次扫描复用。
- 升级时一次性解除已保存的忽略规则，保留系统目录、链接与运行依赖保护；曾被忽略的目录可重新扫描。
- 标签提供默认无指定颜色和白色，颜色直接用于文字与前面的点，并兼顾浅色背景对比度。
- 给可靠 Mono Unity 游戏添加「未翻译」标签后，排队配置固定版本翻译插件；已有带该标签的游戏也会进入流程。支持已有 ReiPatcher/BepInEx；IL2CPP、未知或冲突加载器需人工处理。
- 首次设置支持 DeepSeek 和自定义 OpenAI 兼容端点，唯一有效的已有本地配置可直接导入；设置体验模式不修改主配置。密钥使用当前 Windows 用户 DPAPI 保存在工作区外，读取 API 和作业不返回密钥。
- 配置完成后询问是否运行，沿用原启动方式；实际启动后再次询问翻译是否成功，仅用户选「是」才移除绑定的未翻译标签。失败可重试或恢复原文件。

### 升级与数据保留

退出 GameLibrary 后安装。数据目录和原游戏保留；迁移至 schema27 前自动保存 SQLite 备份。回退旧版须先恢复相容的迁移前数据库。插件原文件备份加密保存在本机，恢复时检测外部修改；API Key 不随游戏库备份或分发包迁移。

## English

Adds cover paste, Flash directory review and automatic in-game translation plugin setup for Unity, and fixes tag color visibility.

### Highlights and fixes

- Click the cover above Start in details and press Ctrl+V. Folder games use `cover.png`; file games use their own `<stem>.cover.png`. WebP retains `.webp`. Replacements preserve cover history; scanning does not overwrite manual covers.
- Review Flash directories as projects, independent collections or resources. A valid SWF does not prove it is a complete game. Select entries and preview adjustments before confirming. Removing incorrect library records preserves metadata and original files. Mixed folders keep direct SWFs and child projects separate; confirmed decisions are reused.
- Upgrading resets saved ignore rules once, retaining system, link and runtime protections. Previously ignored branches can be scanned again.
- Default/white tag colors apply to text and dots, with contrast adjustment on light backgrounds.
- Adding the untranslated tag to supported Mono Unity games queues pinned plugin setup. Existing tagged games are included. Existing ReiPatcher/BepInEx are supported; IL2CPP, unknown and conflicting loaders require manual handling.
- First-use settings support DeepSeek and custom OpenAI-compatible endpoints. A unique valid existing local configuration is imported automatically. The demo leaves real settings unchanged. Keys use current-user Windows DPAPI outside the workspace and never appear in read APIs or job results.
- After setup, users choose whether to launch through their existing profile, then confirm translation results. Only explicit success after an actual launch removes the bound untranslated tag. Retry and original-file restore are available.

### Upgrade and data preservation

Quit GameLibrary before installing. Library data and original games are retained. A SQLite backup precedes schema27 migration; rollback requires a compatible pre-migration database. Plugin backups are encrypted locally; restore refuses externally modified files. API keys are excluded from library backups and distribution packages.

### Validation and limitations

See the [validation record](https://github.com/sumingwang233/GameLibrary/blob/main/docs/releases/v1.7.2-validation.md) for executed checks and pending acceptance. Setup downloads public pinned plugins and validates them offline; it does not launch games or call paid translation APIs. After users launch, plugins use the locally configured service. Provider charges depend on the user's account and usage.

Final desktop, real translation results, clean Windows10/11, DPI and production installer manual acceptance remain pending. This is a pre-release; stable downloads remain at v1.5.5. If publisher signing is unavailable, Windows may show an unknown-publisher prompt. Verify packages against the versioned SHA-256 manifest.
