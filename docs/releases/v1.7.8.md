# v1.7.8 — Unity 中文字体后备修复

**待验收预发布。** 修复自动配置 Unity 翻译插件时没有中文后备字体、导致部分汉字显示方框的问题。

- Unity UI 使用本机已有中文字体，TextMeshPro 按 Unity 代际配置 Xiaolai 缺字后备字库，附带许可，不安装系统字体。
- 保留自定义字体、翻译缓存及最初备份；固定哈希包首次下载后复用缓存。
- 启动时修复此前托管的中文插件，即使已经移除“未翻译”标签。正在运行、拒绝和未托管安装保持原状。
- 保留插件运行后补写的 INI 默认项；升级失败仅撤回本次修改。

关闭游戏，升级并重启 GameLibrary，等待旧托管安装补齐字体后再启动游戏检查缺字和布局。首次下载需联网；未知版本和自定义字体保留原配置，特殊 TMP 版本仍需验收。schema 27 不变，私人 API key 留在本地，安装包未签名。

## English

**Prerelease awaiting acceptance.** Adds missing Chinese font configuration to managed Unity translation installations. Unity UI uses an installed CJK font; TextMeshPro uses a pinned Xiaolai fallback bundle for the detected Unity generation, with licenses included.

Custom fonts, translation caches and original backups are preserved. Startup repairs previously managed Chinese configurations even without the untranslated tag. Running games, declined attempts and unowned installations remain unchanged. Updates preserve plugin-generated INI defaults; failures roll back only the current attempt.

Close the game, upgrade and restart GameLibrary, then check missing characters and layout in-game. First font download requires internet access. Unknown versions and custom fonts retain their settings; individual TMP compatibility requires acceptance. Schema remains 27, credentials stay local and packages are unsigned. Full tests and final in-game/manual acceptance have not been performed; this prerelease does not replace the stable channel.
