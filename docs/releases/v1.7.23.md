# GameLibrary v1.7.23

## 简体中文

本版修复 MCP 启动时的工具描述异常、标签批次操作未完整回滚的问题，并恢复当前源码的 CI 检查。2026-10-22 正式发布并设为 Latest，使用已通过人工验收的原始安装包。

### 主要变化

- 格式检查独立运行，不再因格式错误跳过整个 .NET 构建和测试 job。
- CI 支持手动触发，同一分支的新运行会取消旧运行；.NET 测试上传 TRX 结果供排查。
- 图谱检查导出报告附件，避免第三方 action 在读取 token 身份时失败。
- 保留 v1.7.22 的 Godot 识别与 MTool 翻译支持，以及 v1.7.21 的手动已游玩标记。

### 修复

- 可选 JSON 参数改用可空类型，并从原始 MCP 请求保留显式 null；工具描述可正常生成，省略参数仍表示保持原值。
- 嵌套事务使用 SQLite 保存点。标签重排出现修订冲突时，已执行的批次修改一并回滚。
- 启动观察在同一进程存活期间重试读取主模块，避免刚启动时暂时读不到路径，导致自动入口一直无法通过验证；保留启动时间和目录边界核验。
- 30 秒启动验证测试在验证完成后才退出测试进程，消除固定 31.5 秒存活窗口带来的调度竞争；保留 29 秒前不能成为默认入口的断言。
- 封面生命周期和 MCP 扫描测试补齐契约要求的修订号、游戏 ID 与幂等键；按既有规则整理 C# 格式和 using 顺序。

### 升级与数据保留

退出托盘中的 GameLibrary 后安装新版。本次修复没有新增数据库迁移。回退前请备份游戏库，并确认目标版本兼容现有数据。

## English

This version fixes MCP startup schema errors and incomplete rollback of tag batches and restores CI checks. It was formally published and marked Latest on 2026-10-22, using the original packages accepted by the maintainer.

### Highlights

- Formatting runs independently from the .NET build and test job.
- CI supports manual runs, cancels superseded runs on the same branch, and uploads .NET TRX test results.
- Graph analysis exports a report artifact without the third-party action's failing token identity lookup.
- Godot recognition, MTool support and manual played-state marking from v1.7.21–v1.7.22 are retained.

### Fixes

- Nullable JSON parameters and the original MCP arguments preserve the distinction between omitted and explicit null values while allowing schemas to be generated.
- Nested SQLite transactions use savepoints, so a tag reorder conflict rolls back preceding changes in the batch.
- Launch observation retries main-module inspection while the same process is alive, preserving start-time and directory checks when startup module information is temporarily unavailable.
- The 30-second verification test keeps its child process alive until verification completes; its assertion against promotion before 29 seconds remains enabled.
- Cover lifecycle and MCP scan tests supply the revision, game ID and idempotency key required by the contracts. C# formatting and using order follow the existing rules.

### Upgrade and data preservation

Exit GameLibrary from the tray before installing. These fixes add no database migration. Back up the library and check compatibility before downgrading.
