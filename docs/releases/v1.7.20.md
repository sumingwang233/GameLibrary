# GameLibrary v1.7.20

## 简体中文

本次交付本地待验收安装包并推送源码，不创建 GitHub Release。安装包包含 v1.7.19 的已游玩游戏库和 v1.7.20 的回收、扫描与启动修复。

### 主要变化与修复

- 主库默认隐藏已游玩游戏，侧栏“已游玩”可单独查看。搜索、标签和封面筛选在当前列表内生效，数量与分页一致。
- 修复手动添加 EXE 后只回收 EXE 的问题。删除前预览所属游戏目录，确认后回收资源、存档和补丁；共享目录、游戏库根及链接受到保护，合集独立文件保持单文件范围。
- 不再把只有 RPG Maker 资源或 XP3 补丁、没有有效入口的目录扫成游戏；旧候选审核也会检查入口是文件。已有人工确认的记录保留。
- 游戏详情的“启动”页新增 MTool 目录设置，选择包含 `MTool.exe` 和 `loaders` 的目录即可。已有未翻译标签的非 Unity 游戏，可点击“生成或修复 MTool 启动脚本”后开始游戏。
- 启动方式支持 BAT。选择 MTool 生成的脚本时，注入器仍使用原始游戏 EXE；不会把 BAT 当作待注入程序。
- 已评分的游戏再次游玩后，正常返回详情，不再高亮提示评分；仍可手动改分。

### 升级与数据保留

从托盘退出 GameLibrary 后安装新版。升级 v1.7.13 及更早版本或未知版本前，请关闭所有 GameLibrary 实例。本版没有新增数据库迁移；从更早版本升级仍会按既有机制创建快照并迁移。回退程序前，请确认库兼容性。

安装不会自动清理历史游戏文件。个人删除核查报告只保留在本机；删除原文件仍需用户明确确认。BAT 中的命令会以当前用户权限执行，路径和参数中的不支持命令符号会被拒绝。

## English

This delivery provides local acceptance-candidate packages and pushes the source changes. No GitHub Release is created. The packages include the Played library from v1.7.19 and the removal, scanning and launch fixes in v1.7.20.

### Changes and fixes

- Hide played games from the main library and provide a separate Played entry in the sidebar, with consistent filtering, counts and pagination.
- Preview and recycle the full project folder for manually imported EXE games. Shared folders, library roots and links remain protected; standalone collection entries keep their single-file scope.
- Require a valid entry before creating a game candidate from engine evidence. Resource-only RPG Maker folders and XP3 patch folders are excluded; existing accepted records are preserved.
- Add MTool folder settings to the game details Launch tab. Select the folder containing `MTool.exe` and `loaders`, then generate or repair the launch script for an untranslated non-Unity game.
- Support BAT launch profiles. Selected generated MTool scripts retain the original game EXE as the injector target.
- Stop highlighting the rating area after another session when the game already has a rating. Manual rating changes remain available.

### Upgrade and data preservation

Exit GameLibrary from the tray before installing. Close all GameLibrary instances before upgrading v1.7.13 or earlier, or an unidentified version. This release adds no database migration; upgrades from older releases still use the existing backup and migration process. Check database compatibility before downgrading.

Installation does not clean up historical game files automatically. File removal requires explicit confirmation. BAT commands run with the current user's permissions; unsupported command symbols in paths or arguments are rejected.

### Validation and limitations

Development checks passed 170 distinct isolated cases and related compilation, including synthetic BAT execution and recovery of old and new removal intents. Full release gates, real games and translation APIs, final WebView, clean Windows, installation/upgrade/uninstallation, language/DPI and keyboard acceptance remain unrun. This is not a stable release and was not installed automatically. See the [build record](v1.7.20-validation.md) for production compilation, signing and package integrity results.
