## 修复与边界

`TitleTranslationClient.TranslateAsync` 在两个提供商共享的成功路径校验响应，原文含 `-` 时，将译文连续两个或更多 `—` 收为 `：` 并移除首尾包围符及两侧空白；结果为空按 invalidResponse 处理。单个 / 批量与 CLI / MCP 共用该入口。原文、手动编辑路径和无原文连字符的标题保持原样。

示例 `カノジョの性癖 -盗聴×妄想-`、模拟引擎响应 `女友的癖好——偷听×妄想——`，在完整 Host 作业中保存并显示为 `女友的癖好：偷听×妄想`。此为可控 HTTP 响应回归，没有调用公网翻译或发送用户标题。

已有译名仍默认跳过；详情重新翻译可应用新规则。不批量重写既有数据，不新增字段、依赖或数据库迁移，schema26 与 v1.7.0 相容。较旧版本的回退边界见 [名称翻译](../title-translation.md)。
