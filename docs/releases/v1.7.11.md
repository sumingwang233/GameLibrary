# v1.7.11 — Unity 加载器与现代 TMP 兼容修复

**待验收预发布。** 修复已确认的 Unity 6 IL2CPP 加载器兼容问题、恢复后无法重试的问题，并改善 Mono 双加载器与现代 TMP 中文字体处理。真实游戏运行效果仍需确认。

- Unity 6 IL2CPP：对已固定版本及哈希的运行组件应用受限 Hook 修复；新安装、显式重试及已托管安装使用同一检查，未知组件不自动修改。
- 恢复后重试：识别非活动的已知加载器缓存和生成程序集，复用恢复收据重新安装；不删除未知文件或覆盖无法核验的模组。
- Mono 双加载器：完整 BepInEx 与可核验 Rei 引导同时存在时，只停用重复的 Rei 引导调用，保留 BepInEx 和现有 MOD。适用于已诊断的 testDrugs、HerMarionetteCommands 布局。
- 现代 Mono TMP：在支持的游戏中使用系统中文字体，让游戏自身生成字体材质与图集，避免旧字库与新版 TMP 不兼容。已确认的旧 Rei 组件逐文件核验后升级到 XUnity.AutoTranslator 5.6.2；保留兼容的自定义字体。
- 启动页按钮改为“自动识别启动方式”，移除 30 秒解释段落及冗余入口证据文案；四语言同步。

先关闭游戏并退出 GameLibrary，再安装新版或替换便携版程序。原游戏资源、游戏库及私人凭据保留，API key 不进入安装包或 GitHub；schema 保持 28。已有插件可从详情页点击“配置或重试翻译插件”，完成后仍需实际运行确认；未知或修改过的加载器不会强制覆盖。

后端 77 个当前专项用例均有分批通过记录，前端专项 30 项及四语言检查通过。生产编译和交付证据见[验证记录](https://github.com/sumingwang233/GameLibrary/blob/main/docs/releases/v1.7.11-validation.md)。未执行全量测试、真实游戏运行、在线翻译及最终安装/升级/卸载、干净 Windows 与 DPI 人工验收。batheGirl 贴图消失的完整原因仍待运行日志和画面确认；不宣称本版已验证所有报告游戏。安装包未签名，Windows 可能提示未知发布者，请核对同版本 SHA-256 清单。预发布不替换稳定渠道。

## English

**Prerelease awaiting acceptance.** Addresses the diagnosed Unity 6 IL2CPP loader compatibility issue, retry after restore, verifiable Mono dual-loader layouts and modern TMP Chinese fonts. Actual game behavior remains unverified.

Known Unity 6 runtime binaries receive a narrowly scoped Hook fix shared by fresh installation, explicit retry and managed-installation repair. Restore receipts and recognized inactive generated files no longer prevent retry; unknown files remain protected. When complete BepInEx and a verifiable Rei bootstrap coexist, only the duplicate Rei bootstrap call is disabled, preserving BepInEx and existing mods.

Supported modern Mono TMP games use installed Chinese system fonts and the game's own font/material generation instead of incompatible old font bundles. Known older Rei runtime files are individually verified before upgrading to XUnity.AutoTranslator 5.6.2. Compatible custom fonts are preserved. The launch page also simplifies automatic entry detection wording in all four languages.

Close games and quit GameLibrary before installing or replacing portable files. Library data, original game resources and local credentials are preserved; schema remains 28. Existing plugins can be checked using configure/retry in game details. Unknown or modified loaders are not forcibly overwritten, and successful configuration still requires in-game confirmation.

All 77 current backend targeted cases have passing records across batches; 30 frontend targeted tests and localization checks passed. See the linked validation record for production compilation and asset evidence. Full suites, real game execution, online translation, final installation/upgrade/uninstall, clean Windows and DPI acceptance were not run. The complete cause of batheGirl's missing textures still requires runtime evidence. Packages are unsigned; Windows may show an unknown-publisher warning. Verify the matching SHA-256 manifest. This prerelease does not replace the stable channel.
