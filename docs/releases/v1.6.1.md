# GameLibrary v1.6.1 — 待验收预发布 / Acceptance pre-release

## 简体中文

新增自动建议启动方式，并包含本会话的界面与 Windows 图标修复。版本号按维护者本次要求登记为 v1.6.1。

### 主要变化

- 对已有及新增游戏识别顶层 EXE，优先符合目录证据的中文入口；保留已有默认配置。唯一可靠建议可直接开始游戏，歧义进入详情的「启动」页选择。
- 建议入口持续运行 30 秒后自动验证，没有默认配置时自动设为默认；跟踪启动器转交的游戏子进程。明确的无效 EXE 或早期崩溃标记为废弃，可手动恢复。
- 正常短退、取消 UAC、权限/环境问题、翻译路由缺失和观察不确定保持待确认；不会根据任意非零退出码废弃入口。

### 修复

- 游戏卡片标题下方显示游玩时长，移除引擎副标题；标题栏新增主题快捷按钮，浅色显示太阳、深色显示月亮。
- 启动时显式绑定当前 EXE 的 Windows 大图标，修复任务栏仍沿用旧图标的情况。
- 手动编辑已验证入口时保留已有默认标记；备份恢复任务先保存结果再报告完成，避免重启后短暂找不到结果。

### 升级与数据保留

先退出 GameLibrary，再安装新版或替换便携包。保留原游戏和数据目录。数据库 v24 自动迁移到 v25并保存迁移前快照；原手动参数、工作目录和默认配置保持原样。回退旧程序前先备份，旧版不能直接写入 v25，需要恢复相容备份或迁移前快照。

## English

Adds automatic launch suggestions and includes this session's UI and Windows icon fixes. The maintainer explicitly requested version v1.6.1.

### Highlights

- Discovers top-level EXEs, prefers Chinese entries backed by directory evidence, and preserves existing defaults. A unique reliable suggestion can launch immediately; ambiguous entries require selection in the detail sheet.
- Verifies a suggested game after 30 continuous seconds and promotes it only when no default exists. Tracks game children after launcher handoff. Invalid EXEs and confirmed early crashes are discarded with manual recovery.
- Short normal exits, UAC cancellation, permission/environment issues, missing translation routes and uncertain observation remain inconclusive. Arbitrary nonzero exit codes never justify automatic discard.

### Fixes

- Card playtime replaces the engine subtitle. The titlebar theme shortcut shows a sun in light mode and a moon in dark mode.
- Explicitly binds the current executable's large Windows icon so the taskbar receives the updated icon.
- Preserves an existing default when manually editing a verified entry. Restore jobs persist their final result before reporting completion, preventing missing history immediately after restart.

### Upgrade and data preservation

Quit GameLibrary before installing or replacing portable files. Keep your original games and library data. Schema v24 migrates to v25 with a pre-migration snapshot; manual arguments, working directories and defaults are retained. Older applications cannot write v25: back up first and restore a compatible backup or snapshot before rolling back.

### Validation and limitations

- Read-only audit of 295 existing defaults: 231 direct suggestions matched manual choices, 61 required selection and 3 had no suitable entry. No user games were launched.
- All 592 .NET and 31 frontend tests passed. Distribution packages passed internal and external SHA-256 validation; see the [validation record](https://github.com/sumingwang233/GameLibrary/blob/main/docs/releases/v1.6.1-validation.md).
- Actual automated results are recorded in the generated `release-validation.json`. Isolated process tests cover the real 30-second boundary, launcher handoff and migration safeguards.
- Clean Windows 10/11, all DPI settings, real sample games and keyboard acceptance remain pending. This is a pre-release and does not replace stable download links.
- No publisher signing identity was configured. Windows may show an unknown publisher prompt; verify the versioned SHA-256 manifest after downloading.
