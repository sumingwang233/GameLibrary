# GameLibrary v1.7.12

## 简体中文

本次修复 Unity 翻译加载器兼容、Unity 6 字体缺失和重复验证流程。此包为待验收预发布版本。

### 修复与变化

- 已有 BepInEx 6 Mono 加载器配合旧版 XUnity 入口时，日志可能显示加载了 0 个插件。现在对可核验的官方翻译组件适配正确入口，保留原加载器和其他 MOD；未知修改仍需人工处理。
- Unity 6 的旧字体接口可能导致方框、文字不显示。自动配置改用可用的字体数组接口与原生 TMP 系统字体，保留自定义字体。
- 应用启动不再自动弹出逐款验证。点击左侧绑定的“未翻译”标签后，按需选择其中一款待验证游戏；回答后返回该游戏详情，不继续弹下一款。
- 后台兼容修复和升级保持已经确认的状态；用户显式重新配置仍会创建新的验证尝试。
- 保留恢复后的生成缓存，支持恢复后再次安装；补丁和新组件在同一备份事务中，失败时还原本次修改。

### 升级与下载

关闭游戏后安装。对于此前验证失败或选择“否”的游戏，请在详情中点一次“配置或重试翻译插件”，然后从左侧“未翻译”标签进入按需验证。不会根据旧版运行记录猜测翻译成功。游戏库、游戏文件和本机凭据保留；配置密钥仍只存于本机，不包含在发行资产中。

- `GameLibrary-Setup-v1.7.12.exe`：Windows 10/11 x64 安装器。
- `GameLibrary-Portable-win-x64-v1.7.12.zip`：免安装桌面版。
- `GameLibrary-Tools-win-x64-v1.7.12.zip`：命令行和 MCP 工具。
- `GameLibrary-v1.7.12-SHA256SUMS.txt`：三个分发包的 SHA-256。

### 验证与限制

已进行脱敏只读诊断、隔离兼容补丁验证与针对性回归，详情见 [验证记录](https://github.com/sumingwang233/GameLibrary/blob/main/docs/releases/v1.7.12-validation.md)。未启动原游戏或请求翻译 API，实际翻译与字体显示、干净 Windows 安装升级、DPI 和全量发布验收仍未执行。安装器未签名；可按随附清单核对下载文件，但哈希不代表发布者签名。

## English

This prerelease fixes Unity translator loader compatibility, Unity 6 font failures, and repeated confirmation prompts.

- Adapts verified official XUnity Mono entries to an existing BepInEx 6 loader while preserving the loader and other mods. Unknown modifications require manual review.
- Uses a compatible font-array API and available native TMP system-font support for Unity 6; custom fonts are preserved.
- Startup no longer opens a confirmation queue. Click the bound untranslated tag in the sidebar, choose one game, and return to its details after reporting the result.
- Background repairs retain confirmed state. Explicit reconfiguration starts a new confirmation attempt.
- Reinstallation supports retained generated metadata, with compatibility changes inside the existing backup/rollback transaction.

Close the game before installation. For previously declined or unsuccessful configurations, choose the configure/retry action in game details once, then validate through the sidebar tag. Library data, original games, and local credentials are retained. No private API key is included in release assets.

Download the Setup, Portable-win-x64, Tools-win-x64, and versioned SHA256SUMS assets listed above. Targeted checks and isolated diagnostics are recorded in the linked validation report. Actual game translation/rendering, clean Windows installation/upgrade, DPI, and full release acceptance remain unverified. The installer is unsigned; verify file hashes against the supplied manifest.
