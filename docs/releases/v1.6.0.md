# GameLibrary v1.6.0

## 简体中文

待验收构建。本版本整理了游戏库的并发与恢复流程，增加四语言界面，更新安装向导、图标和项目文档。

### 主要变化

- 安装器、Tauri 和 WPF 支持简体中文、繁體中文、English、日本語；主程序在设置中切换并保存，默认简体中文。
- 使用新的明亮平面图标；安装向导增加清楚的许可、目录、安装摘要和已有版本处理页面。
- 候选审核可整批提交并逐项返回结果；标签排序原子更新，出现修订冲突时回滚。
- 增加中文、繁体、英文和日文 README、品牌 hero、真实截图与录屏脚本，统一发布说明和检查门禁。

### 修复与内部改进

- 请求不再共用覆盖全程的全局锁，列表使用独立读连接与一致快照；会话切换排空租约，避免使用已关闭连接。
- 恢复前检查扫描、备份、后台核对和游戏启动；活动未结束时返回可重试的忙碌错误。恢复采用暂存、原子切换与提交记录，重启时处理未提交恢复。
- 事件发布保留递增序号，长轮询使用独立 bridge；按数据域合并刷新，封面缓存限制为 64 MiB。
- Application 承担用例编排，SQL 按职责拆分；操作目录生成与 CLI/MCP 映射加入一致性检查。
- 打包从当前检出构建，核对版本并记录真实验证状态，不再使用固定主检出路径或无条件写“全部通过”。

### 升级与数据保留

先退出 GameLibrary。安装新版或替换便携版程序文件，保留默认数据目录 `%LOCALAPPDATA%\GameLibrary` 与原游戏文件。升级前备份游戏库；回退前确认旧版数据库兼容性。

## English

Build awaiting acceptance. This version improves concurrent reads and restore handling, adds four interface languages, and updates the installer, icon and project documentation.

### Highlights

- Installer, Tauri and WPF support Simplified Chinese, Traditional Chinese, English and Japanese. Simplified Chinese is the default; desktop language changes are saved in Settings.
- A brighter flat icon and clearer license, folder, summary and existing-version installer pages.
- Candidate review accepts a batch with per-item results. Tag reordering is atomic and rolls back on revision conflicts.
- Four README languages, a brand hero, real screenshots, a recording brief and a consistent release checklist.

### Fixes and internal improvements

- Requests no longer share a request-wide global lock. Lists use independent read connections and consistent snapshots; session changes drain leases before closing connections.
- Restore rejects active scans, backups, reconciliation or game launches with a retryable busy error. Staging, atomic swaps and a commit journal support recovery after interrupted restores.
- Events retain increasing sequence numbers; long polling uses a separate bridge. Refreshes merge by data domain and cover caching has a 64 MiB budget.
- Application owns use-case orchestration; SQL is split by responsibility. Generated operations and CLI/MCP mappings have consistency checks.
- Packaging builds the current checkout, checks versions and records actual results rather than hardcoded paths or unconditional success claims.

### Upgrade and data preservation

Quit GameLibrary before installing or replacing portable application files. Keep the default `%LOCALAPPDATA%\GameLibrary` data folder and original games. Back up before upgrading and check database compatibility before rolling back.
