# v1.7.9 — 最近入库排序与 Unity 自动配置修复

**待验收预发布。** 修复重新加入游戏后“最近入库”仍按旧日期排序，以及 Unity 只有建议入口、尚无默认入口时翻译插件配置失败的问题。

- 明确重新入库更新时间；升级时依据现存确认事件修复受影响的旧记录，保留游戏 ID、收藏、译名和标签。
- Unity 配置复用可信建议入口，必要时自动发现；不提前设置默认，多入口不确定时显示明确原因。
- [toolNeed] 继承的翻译需求、未翻译标签和详情页显式配置共用安装流程；单项/批量接受后自动触发。显式配置无须先添加标签，首次服务商设置完成后继续执行。
- 详情页直接显示提交、检查、安装和失败状态，配置中禁止重复提交；删除“先添加未翻译标签”等静态说明。

关闭游戏后升级并重启 GameLibrary。旧失败且仍需要翻译的项目会重新进入自动检查，也可从详情页点击配置重试。私人 API key 仅保留在本机，不进入源码和分发包。

数据库升级至 schema 28，自动生成迁移前快照；仅有可靠确认事件的历史入库时间会修正，事件已裁剪的不猜测。安装包未签名。专项及编译结果见 [验证记录](https://github.com/sumingwang233/GameLibrary/blob/main/docs/releases/v1.7.9-validation.md)，完整人工验收未执行，不覆盖稳定版。

## English

**Prerelease awaiting acceptance.** Fixes recently-added ordering after re-accepting a removed game, and Unity plugin setup rejecting trusted suggested entries because no default profile exists yet.

Explicit re-acceptance updates the addition time while preserving identity and metadata. Schema 28 repairs existing timestamps only where current-epoch acceptance events provide reliable evidence, with a pre-migration snapshot. Scanner and edit timestamps are not used as substitutes.

Unity setup shares the launch recommendation and translation policy logic, discovers entries on demand, and does not prematurely set defaults. Required folder inheritance, untranslated tags and explicit configuration use the same installation queue; acceptance triggers automation for single and batch reviews. Manual configuration requires no tag and resumes after first provider setup. Details show setup activity and failures directly, with duplicate submission disabled.

Close the game before upgrading and restarting GameLibrary. Credentials remain local; packages are unsigned. Targeted checks and production compilation are documented separately. Full/manual acceptance and actual in-game translation remain pending; this prerelease does not replace the stable channel.
