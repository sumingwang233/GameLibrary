# GameLibrary v1.7.3 — 待验收预发布

## 简体中文

修复升级后大量资源 SWF 仍逐文件显示在待确认列表的问题。

### 修复

- 启动后立即核对包含旧 SWF 候选的扫描根，不再等待默认周期扫描。完整目录审核组与旧候选归并在同一事务提交；新组直接进入待确认列表。
- 只归并完整清单内的旧单文件候选；未读取完整、离线、手动目录及用户已经暂缓、忽略或接受的记录保持原有处理边界。待处理通知同步有效候选数量。
- 明确确认合集后复用选中入口的原游戏 ID、标题、收藏、翻译设置和历史，不恢复未选中的资源；检查主入口文件及实际复用身份的忽略规则，失败回滚整份审核。
- 修复包含非 ASCII 大写字符的文件名漏归并，以及同路径存在多个旧游戏时复用错误记录的问题。

### 升级与数据保留

先退出 GameLibrary，再安装新版或替换便携版程序文件。保留原游戏文件和游戏库数据目录。本版继续使用 schema27，不重新执行 v1.7.2 的过滤重置；历史单文件候选保留归并标记，原游戏记录不因归并自动改变。首次核对可能需要一些时间；目录审核项数量不等于完整游戏数量，模糊目录仍需用户判断用途与入口。

## English

Fixes thousands of legacy resource SWF files remaining as individual pending candidates after an upgrade.

### Changes

- Immediately rescan registered library roots containing legacy SWF candidates. Commit complete directory groups and retirement of covered legacy candidates together; replacement groups are immediately reviewable.
- Preserve games, source files, manual roots and user review decisions. Incomplete or offline directories are not retired; pending notifications show the current review count.
- Explicit collection approval reuses the selected entry's original game ID and metadata. Unselected resources stay removed. Validate both the selected entry and the identity actually reused against ignore rules; roll back failed reviews.
- Handle Unicode filename case correctly and avoid restoring the wrong record when a path has multiple historical games.

### Upgrade and downloads

Exit GameLibrary before installing or replacing portable files. Keep the existing library data directory and original games. Schema27 is unchanged and the v1.7.2 ignore reset is not repeated. The first regrouping scan can take time; directory review counts are not counts of complete games.

Download Setup for installation, Portable for the desktop app, or Tools for Host/CLI/MCP. Verify the three packages with `GameLibrary-v1.7.3-SHA256SUMS.txt`.

### Validation and limitations

An isolated database copy reduced 7,696 legacy pending SWF entries to 1,072 directory reviews without changing existing game rows. Explicit approval of a 683-entry collection and an EXE project with 34 resource SWFs succeeded. See the [validation record](v1.7.3-validation.md) for build evidence. The installer is unsigned and final-package manual acceptance is incomplete; this is a prerelease.
