安装中的旧版 Host 在20逻辑处理器上，36秒采样的系统CPU平均0.56%、峰值2.47%；未复现持续10%。dotnet-stack 采样捕获 LaunchSuggestionService.DiscoverAsync 内的 SQLite 读取。源码每5秒全库发现，并在缓存判断前逐项查询游戏；候选路径核对每30秒重复加载整库详情及归并历史。
