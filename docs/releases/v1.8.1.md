# GameLibrary v1.8.1 · 扫描与重复入库修复（待验收）

## 简体中文

修复扫描新游戏时只发现磁盘根目录、漏掉子目录游戏的问题，并阻止快捷方式与游戏本体重复入库。本次为待验收预发布，不设为 Latest。

### 修复

- 磁盘根目录中的独立 Godot EXE 按文件生成候选，扫描继续进入其他游戏目录。
- ExactPath 忽略只跳过指定目录自身，保留子目录扫描；Subtree 和系统目录边界仍生效。
- 待确认徽标只显示候选总数，不再把同一批候选的通知重复计数。
- 自动扫描忽略 LNK。手动导入快捷方式、扫描本体以及接受已有候选共用保守入口身份检查，避免同一安装重复建卡；不同安装及无法确认的关系保留审核。
- 保留 Tauri 生成的压缩 sidecar，避免桌面分发包遗漏所需的 Host/Bridge 载荷。

### 升级与数据保留

先从托盘退出旧版，再安装或替换便携版。保留游戏库数据目录和原游戏文件；本版无数据库结构迁移。升级后重新扫描游戏库，旧的未绑定磁盘根候选会在成功观察后退出待确认列表。不要把本版当作其他工作区尚未提交的 Bridge/退出优化合集。

## English

Fixes scans that stopped at a drive root and missed new games in subfolders, and prevents duplicate shortcut/game records. This is an acceptance candidate, marked as a pre-release rather than Latest.

### Fixes

- Standalone Godot executables at drive roots become file candidates; scanning continues into other installations.
- ExactPath ignores preserve descendant discovery; subtree and system exclusions remain enforced.
- Pending badges count candidates once, without adding their notification count.
- Automatic scans ignore LNK files. Manual shortcut import, discovery and candidate acceptance share conservative entry checks; ambiguous or different installations remain separate.
- Desktop packages retain the compressed sidecars produced by Tauri.

### Upgrade and downloads

Quit the old application from its tray before upgrading. Keep the library data directory and original games; no database schema migration is introduced. Rescan after upgrading. The four assets above provide the installer, portable application, advanced tools and SHA-256 checksums.

### Validation and limitations

Targeted checks passed: 135 distinct .NET cases, three Sidebar cases and frontend type checking. See the linked build record for this package's actual checks. Real-game scans, Windows installation/upgrade/uninstall and multilingual DPI acceptance remain unverified. Executables are unsigned and may trigger an unknown-publisher warning.
