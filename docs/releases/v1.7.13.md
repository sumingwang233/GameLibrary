# GameLibrary v1.7.13

## 简体中文

修复 Flash 独立游戏合集审核入库后没有建议启动方式的问题。此包为待验收预发布版本。

### 修复与变化

- 合集审核中多选的每个 SWF/EXE 文件均按独立游戏入口生成建议启动方式，不再重新猜测同目录中的其他文件。
- 大型合集不再因目录超过 256 个文件而缺少建议；小型合集的 SWF 入口同样支持。
- 升级后自动补齐此前已入库的独立文件游戏。用户手动设置的默认方式和删除/废弃的建议保留。
- 建议入口仍需实际运行验证，审核入库不会直接将其标为运行成功或默认方式。

### 升级与下载

退出 GameLibrary 后安装。已确认的合集无需重新录入；保持游戏库目录在线，后台会补齐缺失建议。游戏库数据和原游戏文件保留。SWF 沿用 Windows 已配置的文件关联，仍需本机具备相应播放器。

- `GameLibrary-Setup-v1.7.13.exe`：Windows 10/11 x64 安装器。
- `GameLibrary-Portable-win-x64-v1.7.13.zip`：免安装桌面版。
- `GameLibrary-Tools-win-x64-v1.7.13.zip`：命令行和 MCP 工具。
- `GameLibrary-v1.7.13-SHA256SUMS.txt`：三个分发包的 SHA-256。

### 验证与限制

针对性回归使用随机隔离目录、真实扫描和公共管道审核链路，未运行真实游戏。生产编译完成，打包与验证结果见 [发行验证记录](https://github.com/sumingwang233/GameLibrary/blob/main/docs/releases/v1.7.13-validation.md)。全量测试、最终安装升级、干净 Windows、DPI 和真实 SWF 播放尚未验收，保持预发布。安装器未签名；可按随附清单核对文件哈希，哈希不代表发布者签名。

## English

This prerelease fixes missing suggested launch profiles after accepting a Flash directory as an independent game collection.

- Each selected SWF or EXE receives a suggestion for its own registered file, without guessing another entry from the shared directory.
- Large collections bypass the generic 256-file discovery limit. SWF suggestions also work for small collections.
- Startup backfills missing suggestions for previously accepted file games. Manual defaults and deleted/discarded suggestions are preserved.
- Directory approval does not mark a launch as verified or make it the default; existing runtime observation still applies.

Exit GameLibrary before installing. Previously accepted collections do not need to be reviewed again. Keep their registered roots available for background discovery. Library data and original game files are retained. SWF launching uses the existing Windows file association and requires a compatible local player.

Download the Setup, Portable-win-x64, Tools-win-x64, and versioned SHA256SUMS assets listed above. Production compilation completed. Targeted regressions use isolated files, actual scanning, and public IPC review operations; no real game is executed. Full tests, final installation/upgrade, clean Windows, DPI, and actual SWF playback remain unverified. The installer is unsigned; verify file hashes against the supplied manifest. See the linked validation report for details.
