# GameLibrary v1.8.0

## 简体中文

这一版把游戏库的批量整理做成一次操作，并修掉了后台服务重启后需要手动重启程序的连接问题；经常一次处理几十个游戏的用户会直接感受到差别。

### 主要变化

- 选中多个游戏后，收藏、加标签、移出游戏库各走一次批量请求，逐项返回结果。以前每个游戏要单独查询再写入，几十个游戏会卡上一会儿。
- 桌面桥接、CLI、MCP 和桌面端分别声明自己需要的权限，不再默认拿到全部能力；`access.admin` 不发给任何客户端。
- 详情面板刷新后显示最新标题、收藏与封面；审核时部分失败的项目留在勾选状态，不用重新挑一遍。
- 徽章文字对比度达到 WCAG AA，详情面板的标题与焦点顺序修正，游戏卡不再把复选框和启动按钮塞进同一个按钮角色里，扫描进度不再每秒播报，动画遵循系统的减少动态设置。

### 修复

- Host 进程退出后，桥接层缓存了失效连接，后续请求会一直报「尚未完成握手」。现在会重建连接，并在同一次请求上重试一次；非连接类错误不会重试。
- 扫描与标题翻译轮询遇到作业丢失（`NotFound`）会一直转下去；连接连续失败也会无限重试。现在前者立即停止，后者连续 5 次失败后停下并给出提示。
- 分页原先用去重后的条数当偏移，遇到重复 ID 会跳过或重复加载；现在按服务端返回的 `nextOffset` 前进，旧响应的回退路径也保留。
- 幂等键只按操作意图生成，参数不同却复用了同一个键；现在键里带参数指纹。
- 安装配置关闭了 `withGlobalTauri`，插件权限从 `default` 收窄到实际用到的几项。
- 新增的中文界面文案补齐了繁體中文、English、日本語三种翻译。

### 升级与数据保留

退出托盘中的 GameLibrary 后安装新版，或替换便携版的程序文件。本版没有新增数据库迁移，游戏库数据目录与原游戏文件保持不变。批量接口是新增操作，旧版 Host 仍能与新版界面配合；如需回退，先备份游戏库。

## English

This release makes bulk library cleanup a single operation and fixes the connection failure that used to require restarting the app after the background service restarted. Users who process dozens of games at once will notice the difference immediately.

### Highlights

- Favorite, tag and remove actions now run as one batch request per action and report per-item results. Previously each game needed its own lookup and write, which stalled on large selections.
- The desktop bridge, CLI, MCP server and desktop app each declare the permissions they need instead of receiving everything by default; `access.admin` is not granted to any client.
- The details panel shows the latest title, favorite state and cover after a refresh. Items that fail during review stay selected, so they do not have to be picked again.
- Badge text contrast now meets WCAG AA, the details panel title and focus order are fixed, game cards no longer nest a checkbox and launch button inside a button role, scan progress no longer announces every second, and animations respect the system reduce-motion setting.

### Fixes

- After the Host process exited, the bridge kept a stale connection and later requests failed with "handshake not completed". The bridge now rebuilds the connection and retries the same request once; non-connection errors are not retried.
- Scan and title-translation polling kept spinning when a job was gone (`NotFound`), and retried forever on connection failures. Missing jobs now stop immediately; repeated connection failures stop after five consecutive attempts with a message.
- Pagination used the deduplicated item count as the offset, so duplicate IDs skipped or reloaded rows. It now advances by the server's `nextOffset`, with a fallback for older responses.
- Idempotency keys were derived from intent alone, so different parameters reused one key; the key now includes a parameter fingerprint.
- The installer configuration disables `withGlobalTauri`, and plugin permissions are narrowed from `default` to the identifiers actually used.
- New Chinese interface strings now ship with Traditional Chinese, English and Japanese translations.

### Upgrade and data preservation

Exit GameLibrary from the tray before installing, or replace the portable application files. This release adds no database migration; the library data folder and original games stay unchanged. Batch operations are additive, so the new interface still works with an older Host. Back up the library before downgrading.
