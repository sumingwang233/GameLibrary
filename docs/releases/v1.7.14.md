# GameLibrary v1.7.14

## 简体中文

本版本修复作业、详情编辑、封面缓存、待确认分页与安装升级的可靠性问题。当前为待验收预发布，完整发布门禁和真机验收尚未完成。

### 主要变化与修复

- 待确认列表超过 1,000 项时可加载更多，显示已加载数与总数；批量全选限定为当前已加载项，刷新不会让旧加载结果覆盖新列表。
- 快速切换游戏、关闭后重开详情时，旧响应及错误不再干扰当前页面。简介和标题草稿在后台刷新、冲突或保存期间继续输入时保持，并由用户明确重试。
- 修改某个游戏封面时保留其他游戏正在加载的封面；切换库身份/纪元仍拒绝旧库响应。
- 作业终态记录失败会显示原因并保留原执行结果；恢复存储后只重试记录，避免重复执行业务，未可靠记录时阻止恢复维护。
- 请求已发送后的取消或协议异常不再留下可复用的失步管道；不兼容握手准确返回 Host 的 API 版本。
- 审计追加与轮换串行处理，写入失败可诊断；最近日志优先从新文件读取。减少详情重复配置查询并稳定卡片选择回调。
- 安装和卸载检查目标进程的实际路径，无法安全继续时提示退出并中止，取消按名称全局强杀。升级旧版前另行保护其他安装实例。

### 升级与数据保留

升级 1.7.13 及更早版本或无法识别的版本前，请退出所有 GameLibrary 实例，包括托盘与后台服务；这是对旧卸载器行为的兼容保护。新安装器和 1.7.14 卸载器按安装目录核对进程，路径无法确认也会中止。

安装新版或替换便携版程序文件，保留游戏库数据目录与原游戏。无新增数据库迁移、operation 或依赖；卸载仍仅清理已知程序文件并保留未知文件。完整安装/升级/卸载流程尚未人工验收；回退前备份游戏库。

## English

This release improves reliability across jobs, game details, cover loading, candidate pagination and installation. It is an acceptance prerelease; full release gates and manual acceptance are incomplete.

### Highlights and fixes

- Pending candidates beyond the first 1,000 can be loaded in batches. Counts and selection describe loaded items; older appends cannot replace a newer refresh.
- Switching or reopening game details ignores stale responses and errors. Title and summary drafts survive refreshes, conflicts and typing during a save; retries remain explicit.
- Updating one cover preserves unrelated cover requests. A library identity or epoch change still rejects old-library results.
- Failed final job recording retains the original execution result for record-only retry. Restore maintenance is blocked while results remain unrecorded.
- In-flight cancellation and protocol failures invalidate the affected pipe. Incompatible handshakes report the actual Host API version.
- Audit append and rotation are serialized, write failures are observable, and recent-log reads start from newer files. Duplicate initial profile reads and unnecessary selection changes are reduced.
- Setup and uninstall verify executable paths and stop with a close-and-retry message when unsafe. Global process-name termination is removed, with additional protection before invoking older uninstallers.

### Upgrade and data preservation

Before upgrading version 1.7.13 or earlier, or an unidentified version, close all GameLibrary instances, including tray applications and background services. This protects other installations from older uninstallers. New setup and the 1.7.14 uninstaller check processes within the affected installation; unknown process paths also stop the operation.

Install the update or replace portable application files while keeping the library folder and original games. No database migration, operation or dependency is added. Uninstall still removes only known application files and preserves unknown files. The full installation/upgrade/uninstall workflow has not been manually accepted; back up the library before rollback.
