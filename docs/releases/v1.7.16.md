# GameLibrary v1.7.16

## 简体中文

本版本修复 MTool 生成配方无法启动的问题，并包含 v1.7.15 新增的封面筛选。当前为待验收预发布，完整发布门禁和真机验收尚未完成。

### 主要变化与修复

- 游戏列表新增“不限封面 / 有封面 / 无封面”，可与搜索、标签、收藏组合，并随收藏夹保存和恢复；总数与分页都由数据库筛选。
- 识别 MTool 真实生成脚本中的 `@chcp`、`@cd`、`@echo`；支持固定绝对工作目录，同时保留 `%~dp0` 的脚本目录语义。
- 保留 `MTool_Game.exe` 和 `MTool_Game_Tmp` 中的生成入口，避免错误替换成原始 EXE；生成入口、工具、Hook 和工作目录缺失时明确阻止启动。
- 支持已观察到的 BakinLauncher 配方，沿用有界等待和工具启动顺序；不直接执行 BAT。
- 非 Unity 游戏不再统一收到 BepInEx/XUnity 插件建议；启动预览与执行使用同一恢复建议。

### 升级与数据保留

先从托盘退出 GameLibrary，再安装新版或替换便携程序文件，保留游戏库数据目录与原游戏。升级 v1.7.13 及更早版本或未知版本前，请关闭所有 GameLibrary 实例，以兼容旧卸载器。无新增数据库迁移或依赖；回退前请备份游戏库。

## English

This prerelease fixes launch failures with generated MTool recipes and includes the cover filter added in v1.7.15. Full release gates and manual acceptance remain incomplete.

### Highlights and fixes

- Filter the library by all, with or without a current cover, combine other filters, and save the condition in a collection. Counts and pagination use the same database filter.
- Parse generated `@chcp`, `@cd` and `@echo` lines and fixed absolute working directories while keeping `%~dp0` relative to the script.
- Preserve generated `MTool_Game.exe` and `MTool_Game_Tmp` entries instead of replacing them with the original executable. Missing entries, tools, hooks or working directories block the launch with a reason.
- Support the observed BakinLauncher recipe with bounded loader waiting and the existing tool sequence. BAT files are parsed, not executed.
- Non-Unity games no longer receive a blanket BepInEx/XUnity recommendation. Preview and execution share recovery guidance.

### Upgrade and data preservation

Exit GameLibrary from the tray before installing or replacing portable files. Keep library data and original games. Before upgrading v1.7.13 or earlier, or an unidentified version, close every GameLibrary instance to protect against older uninstallers. No database migration or dependency is added; back up the library before rollback.

### Validation and limitations

- Build source: `694583f`. All 63 focused MTool checks passed; 69 focused cover-filter checks passed at `bea2941`. Related compilation and localization passed; see the [cover](../development/v1.7.15-cover-filter.md) and [MTool](../development/v1.7.16-mtool-launch.md) records.
- All 15 inspected local recipes parse, but seven reference missing tool programs and three reference missing generated entries/caches. Regenerate these recipes in MTool. Static inspection does not establish successful in-game translation.
- Full automation, final desktop execution, real MTool/game/API operation, installation/upgrade/uninstall, clean Windows, DPI and keyboard acceptance are incomplete. This is not the latest stable release.
- Actual signing, final checksums and production build results are recorded in the [release validation record](v1.7.16-validation.md). Verify downloads against the manifest; checksums do not authenticate the publisher.
