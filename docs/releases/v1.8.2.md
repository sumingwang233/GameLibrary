# GameLibrary v1.8.2 · 桌面资源占用优化（预发布）

## 简体中文

减少桌面后台进程和大库界面的资源保留，继续使用现有游戏库数据格式。维护者本机人工验收已通过；本次作为预发布，不替换 v1.8.1 的 Latest。

### 主要变化

- 两个常驻 Bridge 合并为一个，普通操作和事件长轮询使用独立连接，等待事件期间仍可处理操作。
- 网格和紧凑布局只挂载可见行及邻近行；封面按需读取、限制并发，屏外或关闭详情后移除排队消费者。
- 隐藏窗口时合并普通刷新，显示后补齐；保留事件消费和游戏退出唤醒，空闲 Unity 状态查询降低频率。
- 详情、设置等按需加载；近期作业结果保留在内存，旧结果在当前会话暂存并可查询，转存失败时保留原结果。
- 小批已知游戏变更可局部刷新；排序、筛选、库身份或纪元不确定时完整重查。

### 修复

- 父进程退出监视遇到拒绝访问时使用受限回退，保留只停止所属 Host 的清理边界。
- 跨库/纪元的分页不再拼接，旧纪元较高 revision 不覆盖恢复后的记录。
- 保留 v1.8.1 的扫描边界、候选计数、快捷方式去重和压缩 sidecar 发布修复。

### 升级与数据保留

先从托盘退出旧版，再安装新版或替换便携版程序。保留游戏库数据目录及原游戏文件；本版没有数据库结构迁移。默认仍为自包含压缩 sidecar，NativeAOT 候选未启用。

## English

Reduces desktop background processes and retained library UI resources while preserving existing library data formats. The maintainer's local manual acceptance passed. This is a pre-release and does not replace v1.8.1 as Latest.

### Highlights

- One resident Bridge with independent request and event connections.
- Windowed grid/compact rows, bounded cover fetching and cancellation per consumer.
- Deferred ordinary refreshes while hidden, continued event consumption and game-exit wakeup, and slower idle Unity polling.
- On-demand dialogs and session storage for older completed job results, retaining memory results if storage fails.
- Conservative incremental updates with full-query fallback for uncertain membership, ordering or library epochs.

### Fixes

- Access-denied fallback for parent exit monitoring while preserving owned-Host cleanup.
- No page mixing across library identities or epochs, and no stale revision merge after restore.
- Retains v1.8.1 scanning and sidecar publishing fixes.

### Upgrade and data preservation

Quit the old application from the tray before upgrading. Keep the library data directory and original games; no database schema migration is introduced. Default sidecars remain compressed and self-contained; NativeAOT remains an optional candidate.

### Downloads

The four assets listed above provide the installer, portable desktop, advanced tools and SHA-256 manifest.

### Validation and limitations

The maintainer reported local manual acceptance passed with no visible bugs. Tests passed: 919 .NET, 162 frontend and seven Rust cases. See the linked validation record for build, formatting, type and package-integrity results. Automatic WebView/CDP smoke on the final artifacts was not run; full Windows/DPI matrices and whole-desktop memory gains remain unverified. Executables are unsigned and may trigger an unknown-publisher warning.
