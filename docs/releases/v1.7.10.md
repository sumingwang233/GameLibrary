# v1.7.10 — Mono 字体兼容与详情标签拖放

**待验收预发布。** 改善 Mono 翻译插件的中文字体配置，补上已识别中文插件跳过字体修复的链路，并在游戏详情页支持移动标签分类。

- Mono TMP 使用同代中文主字体，修复旧受管配置只设置后备字库的兼容缺口；识别受管字体文件丢失。UGUI 继续使用已安装中文字体，保留自定义字体与 IL2CPP 后备策略。
- 已安装的中文插件在配置/重试时也检查字体；修复前备份，成功配置后等待运行确认，保留插件版本与用户其他配置。
- 游戏详情 → 标签：可把标签拖到其他分类，包括空分类；也可展开“调整标签分类”用下拉框移动。分类对整个游戏库生效，不改变游戏的标签分配。

关闭游戏后升级并重启。旧受管 Mono 安装会自动检查；已有非托管插件可从详情页点击“配置或重试翻译插件”。原游戏资源与私人凭据保留；API key 不进入分发包或 GitHub。数据库 schema 仍为 28。

## English

**Prerelease awaiting acceptance.** Improves Mono Chinese font configuration and adds tag category movement in game details.

Mono TMP uses the matching bundled Chinese font as its primary font instead of relying solely on the global fallback API. Existing custom fonts and the IL2CPP fallback policy are preserved. Already-enabled Chinese plugins no longer bypass required font repair; existing plugins and settings are backed up before modification, with actual success still requiring in-game confirmation.

In game details, drag a tag into any category, including an empty one, or use the accessible category selectors. Categories are library-wide; moving a tag does not assign or unassign it from the game.

Close games before upgrading and restarting. Managed installations are checked automatically; external installations can be checked using the configure/retry button. Schema remains 28 and credentials stay local. The reported game could not be identified, so its actual screen remains unverified. Primary font replacement can change visual style; unknown Unity versions and custom UI frameworks need separate acceptance. Packages are unsigned and this prerelease does not replace the stable channel.
