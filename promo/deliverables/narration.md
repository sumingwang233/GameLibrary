# 旁白稿与配音说明（第一版未配音）

**状态：旁白未录制。** 本版交付的是无旁白成片：字幕文本即为旁白稿，配音位置已按 146 秒时间轴留空。没有用静音文件冒充配音，也没有用机械 TTS 占位。

## 为什么没有配音

- 本机唯一的 zh-CN 语音（SAPI `Microsoft Huihui Desktop`）是桌面朗读音色，读 GameLibrary、Unity、MTool 这类中英混排名称时断句和轻重音不可控，不适合产品片。
- 未安装 edge-tts 等免费神经 TTS，也没有启动付费语音服务（按任务边界不自动购买素材、不启动付费生成）。
- 模型无法试听音频，即使生成也无法验证读音与语气。

## 后续补录方式

1. 用任意免费 TTS（如 edge-tts 的 `zh-CN-XiaoxiaoNeural`）或真人录音，按上表逐句生成/录制，文件命名 `voice-01.wav` … `voice-26.wav`，48 kHz。
2. 在 `promo/audio/` 新增 `voice-plan.json`，把每句放在对应 `at` 时间；`mix.mjs` 已支持 `voice` 字段与音乐闪避参数。
3. 重跑 `node audio/build-plan.mjs` → `node audio/mix.mjs audio/final-plan.json`，再混流。
4. 需要人工确认：GameLibrary / Unity / MTool 三处读音、每句起收是否压到操作点、音乐是否让位。
