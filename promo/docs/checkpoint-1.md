## 3. 与初版分镜相比已做的降级

1. **审核阶段不编辑名称/启动项**：源码中审核列表只有路径与类型，没有名称/启动项字段；镜头改为「审核列表逐项核对 → 入库 → 详情页启动方式」，字幕不声称审核时可编辑。
2. **收藏无单卡按钮**：走「勾选卡片 → 批量收藏」，台词不暗示单卡一键。
3. **系统目录选择器是原生窗口，无法截取**：以影片层绘制的「选择文件夹」面板承接（标 `流程演示`），随后切回真实界面显示已注册目录与扫描结果。
4. **名称翻译结果是模拟响应**：端点真实可用，但拍摄用固定响应，画面标 `示例数据（翻译结果）`。

## 5. 已记录的产品现状（不改产品）

`useGamesQuery.ts:55` 在「全部游戏」下也发送 `played: false`，而 `GamesHandler.cs:63` / `LibraryCatalogStore.Games.cs:162` 把 `false` 解释为“仅未游玩”，因此 v1.7.22 的「全部游戏」会隐藏已标记为已游玩的游戏。演示库内全部游戏保持 `played=false` 以避开展示缺口；该问题写入最终检查报告，不在本工程修改产品代码。
