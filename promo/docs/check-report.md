## 四、已知瑕疵与取舍

1. 详情页内容长，部分镜头为把关键控件抬进安全区，先在拍摄时滚动了面板再截图，因此个别镜头看不到封面顶部。
2. 流程图构图偏简，信息只有三步；已用屏注标明它不是软件页面。
3. 系统目录选择器无法在浏览器中截取，采用重绘面板并明确标注“流程演示”。
4. 产品现状「全部游戏」会隐藏已游玩条目（`useGamesQuery.ts:55` 传 `played:false`），示例库因此全部为未游玩；未修改产品代码。
5. 片尾卡最后 0.6 s 与字幕同屏，字幕不遮挡 URL。
