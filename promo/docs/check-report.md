## 四、已知瑕疵与取舍

1. 字幕与个别动作有 0.5–1 s 的错位（无旁白，靠字幕节奏对画面），例如搜索结果末尾已进入“加入收藏”的句子。
2. 深浅切换为 0.26 s 淡切 + 统一深色字幕底：为了压住单帧亮度跳变，浅色版切换段底部会短暂出现深色字幕带。
3. 目录选择面板是重绘而非系统对话框；已在画面标注，且没有伪造 Windows UI 细节。
4. 部分注释（如「外部工具 …」）贴在画面上方，会短暂压住被虚化的库区文字，不影响关键控件。
5. 产品现状：`全部游戏` 视图会过滤 `played=true` 的游戏（`useGamesQuery.ts:55` 传 `played:false`），示例库因此全部 `played=false`；未改产品代码。

## 五、结论

可作为第一版交付：四支 1080p60 MP4、时间轴与字幕一致、无黑帧、亮度跳变已从首版的 ~100/255 压到 ≤ 25/255。音频与旁白仍待人工确认；旁白未录制这一状态已在交付说明中写明。
